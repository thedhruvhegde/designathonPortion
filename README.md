# Designathon — Impermanence Challenge

> Design something whose value comes from its temporary nature. The solution must embrace disappearance, expiration, transformation, or impermanence as a core feature, not a limitation.

## Repo layout
- `research/case-studies.md` — 30 case studies of designs that are temporary on purpose
- `ideation/futures.md` — 12 concepts, each run through a future (day 1 → year 1)
- `ideation/scorecard.md` — 20-parameter ranking and top 3
